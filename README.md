# Official Watch Briefs

Private archive of full Grok monitoring reports.

Grok email notifications are teasers only. This repo is the place to read the complete brief.

## Layout

- `homeland/YYYY-MM-DD.md` — U.S. Homeland Watch
- `global/YYYY-MM-DD.md` — Global Security Watch
- `index.md` — latest run pointers

Open the dated file. That is the full message.
